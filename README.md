# Awesome Design System Components

A curated list of design systems by tech companies that publish their **UI component source code**.

Inspired by [awesome-design-systems](https://github.com/alexpate/awesome-design-systems). This list is narrower: every entry ships real, usable components, and dead projects are removed rather than kept around.

## Criteria

An entry is listed only if all of the following are true:

- It is built and maintained by a tech company.
- The component source code is public.
- The components can be tried in the browser (docs with live examples, Storybook, or a playground).
- The repository is not archived, and the current version is not marked as deprecated.

Guideline-only systems (e.g. Apple Human Interface Guidelines) are out of scope.
